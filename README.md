# Nikelo Moyo — portfolio

A responsive, buildless HTML/CSS/JavaScript portfolio for GitHub Pages. No installation, API keys or build process required.

## Publish
Upload the CONTENTS of this folder to your GitHub repository, with index.html at the root. Keep assets/, game/, styles.css, script.js and .nojekyll.

In GitHub: Settings → Pages → Deploy from a branch → main → /(root) → Save.

A repository called Nikelomoyo.github.io publishes at https://nikelomoyo.github.io/. Other repository names publish under that repository path. Relative asset links support either option.

## Preview and edit
Open index.html, or run python -m http.server 4173 in this folder.
- index.html: page content and links.
- styles.css: design and mobile layouts.
- script.js: project case studies and native accessible dialogs.
- assets/: genuine local screenshots, favicon and demo photography credits.
- game/index.html: existing browser-game demo. The game requests optional Google Fonts; the portfolio itself needs no external fonts or libraries.

Screenshots contain sample/demo data. The receipt is a CSS concept illustration, not an application screenshot. Preserve snapmix-photo-credits.json when redistributing the screenshot. The newest StudyIntell adaptive features are described as local development; SnapMix and Everyday are local demos. Exact test counts, live deployment claims, unverified achievements, invented contacts and fake testimonials are intentionally absent. Project case studies refer to historical tests without claiming a fresh application regression run.

Repository: https://github.com/Nikelomoyo/Portfolio. Enable GitHub Pages in repository settings to publish the uploaded HTML site. No environment files, databases or credentials are needed to host it.
